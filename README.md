# Weblio英和辞典 ショートカット（Chrome拡張機能）

[Weblio英和辞典・和英辞典](https://ejje.weblio.jp/) で **"検索"** と **"発音を聞く"** を楽にする拡張機能です。

## 機能

1. **単語検索**
   - BS を押すことで、検索文字をクリアし、検索ボックスにフォーカスが移動します。

2. **発音を再生**
   - 検索ボックスにフォーカスがない状態で Enter を押すと、**発音を聞く** ボタンをクリックします。

## インストール方法

1. この `weblio-ejje-shortcut` フォルダを任意の場所に保存
2. Chrome を開き、`chrome://extensions/` にアクセス
3. 右上の「デベロッパーモード」を ON
4. "パッケージ化されていない拡張機能を読み込む" をクリック
5. `weblio-ejje-shortcut` フォルダを選択
