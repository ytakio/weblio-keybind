# Weblio英和辞典 ショートカット（Chrome拡張機能）

[Weblio英和辞典・和英辞典](https://ejje.weblio.jp/) の操作性を改善する Chrome 拡張機能です。

## 機能

1. **入力即フォーカス**
   - ページ上で文字キーを押すと、自動的に検索ボックスにフォーカスが移動します。
   - 押した文字は検索ボックスに入力されます。
   - これまでのように、マウスで検索ボックスをクリックする必要がなくなります。

2. **Enter で発音を再生**
   - 検索ボックスにフォーカスがない状態で Enter を押すと、単語の「発音を聞く」ボタンをクリックします。
   - 検索ボックスにフォーカスがある場合は、通常通り Enter で検索が開始されます。

## インストール方法

1. この `weblio-ejje-shortcut` フォルダを任意の場所に保存します。
2. Chrome を開き、`chrome://extensions/` にアクセスします。
3. 右上の「デベロッパーモード」を ON にします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
5. `weblio-ejje-shortcut` フォルダを選択します。

これで拡張機能が有効になり、`https://ejje.weblio.jp/*` のページで動作します。

## ファイル構成

- `manifest.json` — 拡張機能の定義ファイル
- `content.js` — Weblio ページに注入され、キー入力と Enter を制御するスクリプト
- `README.md` — このファイル

## 注意事項

- この拡張機能は、入力欄（`<input>`、`<textarea>`、`<select>`、contenteditable）にフォーカスがある場合は動作しません。
- ブラウザのショートカット（Ctrl/Cmd/Alt との組み合わせ）や特殊キーは通常通り利用できます。
